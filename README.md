A production-grade, cyber-dark glassmorphic portfolio highlighting standout systems in **AI Automation, Multi-Agent Frameworks, Enterprise POS (Java 17), and Full-Stack SaaS (Next.js 15/16)**.

---

## 🚀 How to Run Locally

1. Open `index.html` in any browser, or
2. Run a local development server:
```powershell
python -m http.server 3000 --directory .
```
Open `http://localhost:3000` in your browser.

---

## 🌐 1-Click Deployment to Vercel (Free)

1. Push this folder to your GitHub:
```powershell
git init
git add .
git commit -m "Initial commit of Mark Chester Santos Portfolio"
git branch -M main
git remote add origin https://github.com/whodakingofhell/<repo-name>.git
git push -u origin main
```
2. Go to [Vercel](https://vercel.com/new), select the repository, and click **Deploy**.
   - Zero build configuration needed.
   - Live instantly with custom domain and automatic SSL.
